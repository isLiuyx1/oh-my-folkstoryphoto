# 验收清单

## 单图硬失败

任一项出现即失败：

- 正式候选不是精确竖版 4:5，或由横图大幅裁切伪装成竖版；
- 拍摄者、拍摄位置或第一视角逻辑不可能；
- 非自拍、合影、定时照中的人物无故直视镜头或停止动作摆拍；
- 画面像宣传照、电影剧照、概念图、游戏截图或专业器材展示；
- 设备能力与故事年代不符，或同段落摄影介质无原因变化；
- 主角换脸、年龄明显变化、固定服装或地点结构漂移；
- 多指、断肢、融合人物、重复人物、严重车辆/船只/建筑错误；
- 可辨认乱码、字幕、水印、平台 UI 或品牌标志；
- 前段提前出现最终奇观；
- 图片无法独立对应字幕或承担多个冲突信息点。

## 七项摄影红旗

逐张计数：

1. 人物居中；
2. 人物直视镜头；
3. 光线均匀且脸部完美补亮；
4. 前景和边缘完全干净；
5. 人物全身、道具和背景都被完整展示；
6. 全画面商业级锐利；
7. 构图像肖像、剧照、宣传照或器材展示。

同一张达到三项即失败。返修优先改变拍摄行为、机位和人物视线，不得只加噪点。

## 单图通过条件

- 无硬失败；
- 摄影红旗少于三项；
- 拍摄者、原因、站位、人物意识、保留理由和设备结果均可解释；
- 构图/成像不完美由场景导致，不是统一滤镜；
- 身份、空间、时代和字幕对应正确。

## 整篇

- 图数、分镜、字幕、提示词和发布说明一致；
- 现实生活约占 60%，异常逐步增加；
- 至少三种拍摄位置和两种拍摄来源；
- 同一角色、地点、设备、车辆和道具连续；
- 最终证据重新解释至少三个前文细节；
- 恐怖不靠连续鬼脸，庄严题材不被无故恐怖化；
- 来源、推测与虚构边界清楚；
- 最终成片全部为 1080×1350 PNG。

## 停止门槛与非阻断异常

- 全部原图首审结束并生成返修报告后，必须停止等待用户批准全部或指定返修图号；
- 自动修复一次后仍存在任何硬失败时，只把该内容项设为 `needs_user`；先继续其他独立可运行项；
- 身份或关键地点母版第二版仍无法稳定时，阻止参考图批准，但继续其他参考任务；
- 合格图片数不足且继续生成将超过返修上限时，记录缺项并继续不受影响的任务；
- 两个不同任务出现相同后端传输错误时记录后端健康告警，但继续逐项尝试，不触发阻断性后端熔断；
- 单项耗尽三档参考恢复后标为 `transport_blocked`；不得停止整个项目，继续其他参考图、分镜、返修和批次，全部可运行项结束后统一生成《生成阻塞报告》；
- 用户未明确授权时不得切换 CLI、API 或其他模型；
- 文化、宗教、现实地点或真实事件的改编边界无法安全确定。
