# 可信拍摄与年代设备规范

## 核心优先级

先让照片成为一个可信的人类拍摄事件，再追求画面漂亮、恐怖或震撼。每张正式分镜必须回答：

1. 谁拍的；
2. 为什么此刻会按下快门；
3. 拍摄者站在哪里，受到什么空间限制；
4. 被摄者是否意识到镜头；
5. 为什么这张照片会被保留并进入本篇相册；
6. 当时设备的曝光、对焦、运动或压缩留下什么结果。

无法回答任一项时，先改分镜，不要靠“手机摄影、真实噪点、26mm”补救。

## 全篇拍摄设备档案

在 `07-制作资料/03-角色与视觉设定.md` 固定：

| 字段 | 内容 |
|---|---|
| 故事年代与地点 | 年份范围、国家/地区、城乡环境 |
| 主要介质 | 当代手机、早期拍照手机、数码相机、胶片、监控或扫描档案 |
| 常用视角 | 主摄等效视角与是否允许数码变焦 |
| 动态范围 | 高光与暗部的典型限制 |
| 夜景能力 | 快门、噪点、运动拖影与补光能力 |
| 对焦与锐化 | 自动对焦速度、边缘锐化、压缩软化 |
| 默认画幅 | 原始画幅与最终 4:5 裁切关系 |
| 可用特殊来源 | 自拍、定时、监控、他人转发、档案扫描 |

同一连续段落保持同一设备性格。不得因异常升级突然获得航拍、专业长焦、旗舰 HDR、电影级动态范围或浅景深。

## 年代适配

- **现代普通手机**：允许局部 HDR 痕迹，但避免旗舰宣传片式夜景和全画面无损锐利。
- **早期智能手机**：动态范围窄、暗部彩噪、对焦慢、数码变焦损失明显。
- **功能机/早期拍照手机**：分辨率低、快门滞后、白平衡不稳；构图仍必须由真实行为产生。
- **前智能手机时期**：使用数码相机、胶片、DV 截帧、监控或扫描档案。不要写“普通安卓主摄”。
- **历史时期**：只有故事明确存在现代调查或后世档案时才允许照片；否则调整叙事媒介。

不要机械添加日期戳、假相机 UI、重暗角或复古滤镜。

## 拍摄行为

- 除自拍、合影、证件照和明确摆拍证据外，人物默认不看镜头。
- 优先记录人物继续做事的瞬间：低头收拾、转身说话、递物、赶路、查看手机、揉太阳穴。
- 机位服务于拍摄者处境，不为完整展示人物选择最佳角度。
- 可用位置包括门框后、相邻工位、坐着的同行者胸口高度、车内座位、落后半步或真正第一视角。
- 自拍可看镜头，但应具有手臂距离畸变、自然裁切、背景杂乱或有人未准备好的瞬间。
- 危险场景必须解释为什么仍会拍：下意识记录、远处观察、撤离途中误触、交给他人求证或事后发现自动连拍。

## 构图与成像结果

每张选择 1–2 个行为导致的构图结果：

- 门框、显示器、座椅、背包、树枝、衣袖或同行者切入边缘；
- 主体偏心、头脚自然裁切、距离略远或略近；
- 地平线倾斜约 1–4 度；
- 前景失焦、家具或地形限制最佳视角；
- 拍摄高度来自坐姿、门口、车内或行走状态。

再选择 1–2 个场景适配的设备结果：

- 天空、窗户或灯管局部高光截断；
- 暗部压黑并带轻微底噪；
- 荧光灯、窗光、路灯或帐篷灯形成混合白平衡；
- 手、纸张、车辆、鸟群或人物动作轻微模糊；
- 数码变焦、压缩或锐化导致细节损失；
- 对焦落在前景/背景，主体轻微软焦；
- 潮湿、寒冷或匆忙造成局部镜头污迹；
- 逆光人物脸偏暗而非棚拍补亮。

缺陷必须有因果，不要每张使用相同模板。

## 普通相册测试

在文字自审和最终自审各执行一次：

1. 暂时忽略所有超自然元素。
2. 只看前 60% 现实镜头。
3. 判断它们能否自然属于同一个人的工作、交通、住宿、家庭或调查相册。
4. 检查是否有至少三种合理拍摄位置和两种以上拍摄来源。
5. 任一现实镜头像剧照、宣传照、器材展示或职业摄影作品时，标记失败。

现实基础越普通，后段异常证据越可信。
