# 可信拍摄事件

## 目录

1. 先有拍摄事件
2. 视角物理
3. 因果画质
4. 普通相册测试
5. 三张真实性校准

## 1. 先有拍摄事件

每张图先回答：谁在拍、为什么此刻会拍、设备在哪里、人物是否知道被拍。无法回答时不写提示词。

优先使用普通人会留下的证据：工作记录、随手测试、给朋友看的照片、设备屏幕翻拍、迷路时的路线记录、来不及拍全的异常。不要为了展示奇观发明完美机位。

## 2. 视角物理

- 拍摄者通常不完整入镜；允许手指、袖口、鞋尖、膝盖或设备固定支架自然切边。
- 拍摄者完整入镜只能来自镜面、定时拍摄、设备跌落固定、另一设备或另一人物接拍。
- 当前手机、DV或相机是视角来源时，不得在画面中再次出现完整机身。
- AI分镜的 `设备可见性` 只允许：`不可见`、`仅自然边缘/固定支架`、`由另一采集源拍到`。
- 第三种情况必须在 `拍摄者入镜范围` 写 `第二拍摄源:配置ID`。
- 人物不应自然排成合照，不应持续看镜头；剧情明确要求自拍视频或证词时例外。

## 3. 因果画质

每镜只选一至两项由现场直接造成的缺陷：

| 原因 | 可出现的结果 |
|---|---|
| 奔跑或碰撞 | 方向性拖影、偏斜、局部裁切 |
| 低照度 | 慢快门、暗部彩噪、对焦犹豫 |
| 数码变焦 | 细节涂抹、锯齿或压缩增强 |
| 雨水、海水、雾气 | 局部水滴糊斑、反差下降 |
| 设备跌落 | 贴地视角、遮挡、方向失衡 |
| DV低码率 | 色块、轻微梳齿、运动边缘破碎 |
| 直闪卡片机 | 前景过亮、背景迅速变暗 |

不要无原因堆叠噪点、模糊、过曝、色散和污渍。清晰的普通手机照片也可以真实；关键是构图动机和设备行为成立。

## 4. 普通相册测试

单图同时问：

1. 去掉异常主体后，是否仍像普通人的相册或录像截帧？
2. 拍摄者是否能真实站在这个位置？
3. 画面是否更像记录事件，而不是展示美术设计？
4. 奇观是否被设备拍不全、拍不清或来不及拍，而不是概念图式全貌？

任一答案为否，优先整图重生成。电影布光、英雄机位、商业HDR、专业浅景深、青橙调色、完整怪物展示均为硬失败，不以“只有一个红旗”为由放行。

## 5. 三张真实性校准

参考图获批后，只生成AI分镜标记为以下角色的三张正式图：

- 普通基线：验证日常光线、皮肤、材质与构图。
- 最差拍摄条件：验证低照、运动或遮挡仍来自同一设备。
- 首次重大异常：验证奇观不会把画面升级成电影或游戏截图。

三张均使用正式提示词、正式参考和正式输出路径。逐张结构化审查后制作联系表，与质感锚点并列展示。用户批准后它们直接成为正式通过图；未批准时只调整共享真实性方案、参考角色或提示词规则，不开始整批生成。允许一次校准重跑，第二次仍失败进入 `needs_user`。
