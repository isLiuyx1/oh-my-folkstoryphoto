## 1. 选择规则

新项目先完成并确认 `00-真实性方案.md`，之后才写故事。不要把“真实感”理解成统一的噪点滤镜；先确定是谁、用什么设备、为什么记录，再决定画质。

每篇只设一个主采集配置，最多两个辅助配置。主配置至少承担一半正式图。稳定、受限、失控是同一设备的三个现场状态，不是三种风格：

- 稳定：日常光线、普通自动曝光、自然手持或随手构图。
- 受限：低照、遮挡、数码变焦、狭窄机位等具体限制只造成一至两项缺陷。
- 失控：奔跑、跌落、进水、碰撞或失焦造成方向偏斜、拖影或局部不可读。

## 2. 八类设备

| 设备档案 | 可信表现 | 常见误区 |
|---|---|---|
| 当代中低端手机 | 动态范围窄、自动白平衡漂移、数字锐化、暗部彩噪 | 手机也可以很清楚；不要机械加重噪点 |
| 早期智能机/功能机 | 小底传感器、细节涂抹、偏色、弱防抖、低像素数码变焦 | 不要做成VHS或现代电影胶片 |
| 2010年代存储卡消费级DV | 低码率、弱防抖、慢快门拖影、偏冷白平衡、高光截断 | 不要添加夸张磁带雪花或横向黑边 |
| 1990年代至2000年代磁带式家用摄像机 | 色度分辨率低、轻微隔行、模拟噪声、有限自动曝光、年代合理叠字 | 不要照搬虚构年份；`PLAY`与时间码必须符合设备和剧情 |
| 卡片数码相机 | 直闪、较深景深、过亮皮肤、快门延迟、有限高感 | 不要模拟全画幅浅景深或专业人像灯 |
| CCTV/固定监控 | 固定俯角、广角畸变、压缩块、低帧率、真实监控界面 | 必须解释摄像头位置；不得伪造平台UI |
| 运动相机/执法记录仪/行车记录仪 | 固定佩戴点、超广角、滚动快门、强压缩、震动 | 不要无理由切成漂浮第三人称 |
| 胶片扫描/旧照片/档案翻拍 | 颗粒、冲印偏色、扫描灰尘、纸张反光、边缘损伤 | 区分原照片缺陷与翻拍设备缺陷 |

## 3. 组合规则

- 辅助设备首次使用前必须在故事或前序画面中交代持有者与携带原因。
- 每镜只指定一个实际采集源。当前设备作为视角时，不得同时完整出现在画面里。
- 完整设备入镜必须由另一配置拍摄，并在AI分镜写 `第二拍摄源:配置ID`。
- 横向监控、DV或旧照片只能作为场景内实体载体被竖版拍摄，除非用户明确批准该镜为非摄影例外。
- 设备画质不能因为异世界、怪物或奇观变宏大而升级；异常物只能继承当时设备的限制。

## 4. 质感锚点

技能内锚点位于 `assets/capture-style-anchors/`，清单见其中 `manifest.json`。锚点只学习曝光、压缩、色彩、对焦与构图事故，不学习人物、地点、动作、文字或故事元素。

- `dv-tape-outdoor-01`、`dv-tape-outdoor-02`：家用磁带摄像机感；忽略画面中的虚构1984日期。
- `phone-indoor-candid`：普通室内手机抓拍。
- `phone-obstructed-work`：门框和杂物遮挡的工作记录。
- `phone-lowlight-limited-range`：低照度有限动态范围。
- `phone-narrow-exposure`：狭窄机位与明暗反差。

`capture_style`参考不得与身份或物件参考混为一类。最多两张参考时，按本镜核心连续性决定是否实际输入质感锚点；即使未输入，候选仍必须与批准锚点进行联系表对照。
