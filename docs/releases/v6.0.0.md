# v6.0.0

## 自然文字规则

- 新增人物声音卡、当时知识边界和技术词来源检查。
- 用连续三图测试取代单图独立解释，允许短句、停顿、改口和前图代词。
- 取消发布字幕8字硬下限；保留非空和48字上限。
- 强调的数量差、物件和异常必须在后文回收。

## 工具与状态

- 新增只读 `text_audit.py`，区分硬结构错误和需人工判断的写作警告。
- 新增 `start-text-revision`、`submit-text-revision`、`approve-text-revision` 和 `revert-text-revision`。
- 文字专修会锁定图片状态、参考资产、release manifest 和最终PNG，只允许改三处文字。
- 审批后保存新旧哈希；未批准可一键恢复备份。
